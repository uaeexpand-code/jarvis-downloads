JARVIS 1.14.0 — Windows and Apple Silicon Mac

ChatGPT via Codex now supports multiple saved accounts, Add account and Reconnect, browser sign-in and device-code fallback, default selection and usage refresh. Choose Ask me (default) or opt-in automatic fallback on a verified usage limit. New chats use the default; continued chats retain the selected account. Accounts use separate Codex profiles and require the operating-system credential store. The existing desktop Codex sign-in is preserved. Automatic fallback stops after any partial output or tool execution, avoiding repeated actions; select an account explicitly to continue. Your chats, brain notes, settings, voice and backups remain in the same protected workspace.

Open Settings → AI & connections → ChatGPT via Codex to add an account and finish sign-in on the official OpenAI page. Account sign-in and separate plan limits are handled by OpenAI.
