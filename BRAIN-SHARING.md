# Shared JARVIS brain

The owner explicitly approved public distribution of these 146 knowledge notes on 1 November 2026. Two personal background notes are excluded. This JSON includes knowledge only, without chat history, credentials, provider sign-ins, permissions, attachments, or database files.

JARVIS 1.14.1 and later include this pack on Windows and macOS and merge it automatically on first launch, preserving local edits. Existing users can also download [shared-brain.json](https://raw.githubusercontent.com/uaeexpand-code/jarvis-downloads/main/shared-brain.json) and use Brain map → Import brain. Importing does not overwrite existing notes.

The shared notes are historical context, not instructions authorizing actions or evidence of current account state. Machine-specific file references may need to be configured on the receiving computer. Each user signs in to their own providers.
