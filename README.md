# JARVIS downloads

Windows and Apple Silicon Mac installers are published under [Releases](https://github.com/uaeexpand-code/jarvis-downloads/releases/latest).

This repository contains downloads and publishing scripts only. Application source stays private. Your conversations, notes and connection credentials are never included.

Windows: download and run JARVIS-Windows-Setup.exe. Mac: open JARVIS-macOS-Apple-Silicon.dmg and drag JARVIS into Applications. Grant microphone and desktop permissions when requested. New versions can be installed from Check for updates → Update now.
